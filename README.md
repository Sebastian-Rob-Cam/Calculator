# Simple Calculator

This is a simple calculator application written in Java. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division. The calculator is designed to be easy to use and understand, making it a great project for beginners learning Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Getting Started

To get started with the calculator, clone the repository and compile the Java files. Run the main class to start using the calculator.

```bash
git clone https://github.com/yourusername/Calculator.git
cd Calculator
javac Main.java
java Main
```

## Usage

Follow the on-screen prompts to perform calculations. Enter the numbers and select the operation you wish to perform.
